# Disaster Relief Mesh

A disaster-relief communication system built around **Meshtastic LoRa mesh networking**, Raspberry Pi nodes, and a web-based PWA.

## Overview

The project explores a resilient communication network that can operate when traditional internet and cellular infrastructure is unavailable.

## Technologies

* Meshtastic / LoRa
* Raspberry Pi
* Python
* React / Vite
* Progressive Web App (PWA)
